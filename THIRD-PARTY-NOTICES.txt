ChipSharp third-party notices
=============================

ChipSharp ships code that others wrote, under the licenses below. The runtime's C and assembly is compiled into every
program ChipSharp builds (only the functions a program uses are linked), so a program that contains a piece carries
its notice too. Each source file keeps its own copyright lines and license text as well.

  1. LLVM compiler-rt: soft-float arithmetic (Apache-2.0 WITH LLVM-exception)
  2. Raspberry Pi Pico SDK: the RP2040's second-stage bootloaders, boot2, and its SVD file (BSD-3-Clause)
  3. musl libc: math functions (MIT, with the notices of the code it derives from)
  4. AMD AOCL-LibM (aocl-libm-ose): math functions (BSD-3-Clause)
  5. .NET runtime (dotnet/runtime): library code ported to C# in ChipSharp.Library (MIT)
  6. Espressif: the ESP32-C5's SVD file, and the headers made from it (Apache-2.0)
  7. WCH: the CH32V003's SVD file, as ch32fun keeps it, and the headers made from it (MIT)


1. LLVM compiler-rt
-------------------

Where: src/ChipSharp.Runtime.ArmV6M/CompilerRt (llvmorg-23.1.6, compiler-rt/lib/builtins, unchanged): the float and
double arithmetic, comparisons and conversions of chips without float hardware (the armv6m and avr runtimes).
License: Apache License v2.0 with LLVM Exceptions (SPDX: Apache-2.0 WITH LLVM-exception). Copyright the LLVM Project
contributors. The full license text is src/ChipSharp.Runtime.ArmV6M/CompilerRt/LICENSE.TXT, shipped next to the files.
Its LLVM exception says: "As an exception, if, as a result of your compiling your source code, portions of this
Software are embedded into an Object form of such source code, you may redistribute such embedded portions in such
Object form without complying with the conditions of Sections 4(a), 4(b) and 4(d) of the License."
